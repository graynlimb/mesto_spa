# mesto_spa

Учебная страница для выбора SPA-программы и оставления заявки (тестовое задание: веб-дизайнер / AI-разработчик). Студия и все данные вымышленные.

**Сайт:** https://graynlimb.github.io/mesto_spa/

## Что сделано
- Адаптивная страница: первый экран с предложением, три карточки программ (Перезагрузка, Глубокий отдых, Для двоих), форма заявки.
- Кнопка «Выбрать» на карточке подставляет программу в форму.
- Валидация: пустое имя, не выбрана программа, пустая или прошедшая дата. Ошибки показываются под полями.
- После отправки показывается подтверждение с деталями заявки.
- Заявки сохраняются в `localStorage` и остаются после обновления страницы.
- Дополнительно: отметка «Это подарок» (аудитория включает тех, кто выбирает подарок).
- Стек: один файл `index.html`, чистые HTML, CSS и JS, без сборки. Картинки встроены в файл.

## Как использовался AI
Инструмент: Claude (Anthropic), чат. Время работы: [2 часа].

**Запрос 1 (дизайн и структура):** «Спокойная песочная палитра, один выразительный шрифт для заголовков и один нейтральный для текста. Первый экран: понятное предложение, подзаголовок и заметная кнопка. Три карточки программ, "Глубокий отдых" выделить как самую популярную. Форма ниже, адаптив под все устройства».
Результат: рабочая страница одним файлом с карточками, формой и валидацией.

**Запрос 2 (картинки):** «Вставь картинки по смыслу», с тремя фото кабинетов.
Результат: фото распределены по карточкам: светлый кабинет для короткой «Перезагрузки», кабинет со звёздным потолком для «Глубокого отдыха», кабинет с двумя кушетками для «Для двоих».

## Что пришлось исправить
Первая версия первого экрана: фото ресепшена лежало фоном под полупрозрачной песочной вуалью, чтобы читался текст. На скриншоте это выглядело мутно, а экран был пустым. Я переделал его на две колонки: текст слева на чистом фоне, фото справа в арочной рамке (арки есть на самом фото). Затем проверил экран на 360 и 1440 px.

## Известные недоработки
- Нет backend: заявки хранятся только в браузере, никуда не отправляются. в целом как и надо было.
- Фото взяты из pinterest и нужны только для демонстрации.
- Шрифты подключаются с Google Fonts, без интернета будут запасные.
- Формат поля даты зависит от браузера.
